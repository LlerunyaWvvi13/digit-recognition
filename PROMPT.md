# Промт для создания нейромодели распознавания цифр и чисел

Скопируйте текст ниже в чат с ИИ-ассистентом. Код в этом репозитории написан по этому промту.

---

Ты опытный инженер машинного обучения. Напиши на Python 3.10+ готовый к запуску проект: нейросеть для распознавания рукописных цифр и чисел из нескольких цифр.

## Данные

- Используй набор MNIST через `torchvision.datasets.MNIST` с автоматической загрузкой.
- Отдели 5 000 изображений обучающей части под валидацию. Разделение должно воспроизводиться при том же `seed`.
- Тестовую часть не используй для выбора модели: только для итоговой оценки лучшей эпохи.
- Аугментация только для обучения: поворот до 10°, сдвиг до 10%, масштаб 0,9–1,1, скос до 8°.

## Модель

- PyTorch, сверточная сеть до 150 тысяч параметров.
- Вход 1×28×28, выход — логиты 10 классов.
- Блоки Conv–BatchNorm–ReLU, MaxPool, глобальный average pooling, Dropout и линейный слой.

## Обучение

- AdamW, OneCycleLR, CrossEntropyLoss со сглаживанием меток 0,05.
- Работа на CPU и на CUDA без изменения кода, фиксированный `seed`.
- Сохраняй веса лучшей по валидации эпохи вместе с параметрами нормализации.
- Записывай в JSON историю обучения, точность на тесте, точность по классам и матрицу ошибок.
- Цель: не меньше 99,5% на тесте за 12 эпох.

## Распознавание реальных изображений

- Принимай файл PNG или JPEG любого размера: цветной, серый, с прозрачностью.
- Определяй полярность автоматически: темные цифры на светлом фоне и наоборот.
- Приводи символы к формату MNIST: вписывай в квадрат 20×20 и центрируй по центру масс на холсте 28×28.
- Бинаризацию применяй только для поиска символов, а в сеть передавай полутона.
- Для числа дели строку на связные компоненты слева направо, склеивай разорванные части одного символа, отбрасывай шум.
- Возвращай строку цифр и уверенность по каждому символу.

## Интерфейс

- Обучение: `python -m digit_recognition.train --epochs 12`.
- Распознавание: `python -m digit_recognition.predict путь_к_файлу [--json]`.
- Класс `DigitRecognizer` для использования из другого кода.
- Веса загружай только с `weights_only=True`.
- Понятные сообщения об ошибках на русском: нет файла модели, файл не прочитан, цифры не найдены.

## Проверка

- Напиши тесты pytest: форма выхода сети, обе полярности, деление строки, игнорирование шума, пустое изображение, центрирование, загрузка весов, понятная ошибка при отсутствии модели, точность обученной модели.
- Добавь скрипт оценки чисел: случайные строки из тестовых цифр MNIST с воспроизводимым `seed`.
- Запусти обучение и тесты и укажи фактические значения метрик. Не придумывай результаты.
